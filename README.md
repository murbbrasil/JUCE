# Compatibilidade JUCE para Android 7 - Projeto Murb

## Visão Geral
Este projeto foi criado para garantir a compatibilidade das versões mais recentes do framework JUCE com o Android 7, utilizado no projeto Murb. Ele aborda questões específicas e modificações necessárias para que as aplicações JUCE funcionem perfeitamente na plataforma Android 7.

## Propósito
- Fornecer patches e modificações ao framework JUCE para suportar o Android 7.
- Garantir que as aplicações JUCE possam ser construídas e implantadas no Android 7 sem problemas de compatibilidade.

## Como Começar
1. Clone este repositório.
2. Siga as instruções de instalação na documentação.
3. Integre os patches fornecidos ao seu projeto JUCE.

## Requisitos
- Framework JUCE (versão mais recente)
- Android SDK 7
- CMake ou seu sistema de build preferido
